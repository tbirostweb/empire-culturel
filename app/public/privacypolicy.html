Ce qui est enregistré, et où

Empire Culturel n'a pas de serveur de comptes ni de base de données : la progression est enregistrée uniquement dans le stockage local (localStorage) de votre navigateur, sur votre appareil. Ce stockage est nécessaire au fonctionnement du jeu.

  • Nom de collectionneur (pseudo) ;
  • adresse email saisie à la création d'une partie, utilisée uniquement pour retrouver la partie sur cet appareil, et son dernier email utilisé (pré-remplissage) ;
  • empreinte salée du mot de passe (PBKDF2), jamais le mot de passe en clair ;
  • progression de jeu : ressources, collection, ferme, missions, arbres, prestige, classements, expéditions.

Ces données ne sont pas transmises par l'application à un serveur ni à un tiers. Elles ne vous suivent pas d'un appareil à l'autre et ne sont pas récupérables si vous les effacez. N'utilisez pas un mot de passe important : il ne protège pas contre une personne ayant accès à votre appareil.

Cache de l'application

Un service worker met en cache les fichiers de l'application (pages, scripts, modèles 3D) pour un usage hors ligne. Il ne contient pas vos données de jeu.

Hébergement et journaux techniques

Le site est servi par un serveur web qui peut enregistrer des journaux d'accès techniques (adresse IP, date, ressource demandée). Hébergeur, région, durée de conservation et base légale : À COMPLÉTER. Les polices sont hébergées sur le même serveur : aucune requête vers un service de polices tiers.

Durée de conservation et suppression

Les données locales restent sur votre appareil jusqu'à ce que vous supprimiez la partie (Profil > Supprimer le compte, qui efface la partie et l'email associé) ou vidiez les données du site dans votre navigateur.

Vos droits

Les données de jeu étant uniquement sur votre appareil, vous les consultez et les effacez directement depuis votre navigateur ou l'application. Pour toute demande concernant les journaux d'hébergement ou pour exercer vos droits (accès, rectification, effacement, opposition) : contact ci-dessus (À COMPLÉTER). Vous pouvez aussi saisir l'autorité de protection des données de votre pays (en France : la CNIL). Public visé et âge minimal : À COMPLÉTER.

Monnaies du jeu

L'Or, les Cristaux, les Gemmes, les Tickets, les Matériaux, les Éclats et les Points de compétence obtenus dans le jeu n'ont aucune valeur réelle, ne peuvent pas être retirés ni échangés ; aucun achat n'est proposé.
